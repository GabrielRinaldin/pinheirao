# 🏢 Pinheirão – Meu Sistema de Gestão Condominial

Este projeto surgiu quando me tornei síndico e percebi o quanto a gestão do condomínio era manual e descentralizada.  
Criei o **Pinheirão** para centralizar informações e facilitar a administração.

O sistema foi desenvolvido em **PHP (Laravel)** com **Blade**, **PostgreSQL** e **Google Charts**, com o objetivo de tornar processos mais organizados e acessíveis.

---

## ✨ Funcionalidades

Mesmo não estando finalizado, o projeto já conta com:

- Cadastro e autenticação de usuários  
- Perfis e permissões  
- Registro de movimentações gerais e por residência  
- Emissão de faturas simbólicas para moradores  
- Dashboard com gráficos  
- Envio de sugestões e reclamações

O foco sempre foi transparência, comunicação simples e controle centralizado.

---

## 💡 Motivação

Quis resolver uma dor real: reduzir retrabalho, organizar registros e melhorar a comunicação interna do condomínio.  
Além disso, foi uma oportunidade de aplicar e evoluir meus conhecimentos em Laravel.

---

## 🛠️ Tecnologias

- PHP + Laravel  
- Blade Templates e Bootstrap  
- PostgreSQL  
- Google Charts
